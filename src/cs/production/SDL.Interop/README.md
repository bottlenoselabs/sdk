# bottlenoselabs.SDL.Interop

C# bindings ("unsafe" API) for [SDL 3](https://github.com/libsdl-org/SDL), 1:1 with SDL's C API. `Generated/` is written by `bindgen/SDL/bindgen.sh` from the headers in `ext/SDL`, with [c2ffi](https://github.com/bottlenoselabs/c2ffi) and [c2cs](https://github.com/bottlenoselabs/c2cs); don't edit it by hand.

Part of [bottlenoselabs/sdk](https://github.com/bottlenoselabs/sdk).
