# bottlenoselabs.SDL

An idiomatic C# API ("safe" API) for [SDL 3](https://github.com/libsdl-org/SDL): windows, input, 2D rendering, and the SDL GPU API. Built on `bottlenoselabs.SDL.Interop`, the C# bindings ("unsafe" API) that match SDL's C API 1:1.

Part of [bottlenoselabs/sdk](https://github.com/bottlenoselabs/sdk).
